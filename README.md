## Deskripsi

Repository ini berisi dokumentasi kegiatan workshop Lokakarya Proyek Hari 1, khususnya materi tentang penggunaan AI, Git, dan GitHub.

## Tujuan

Repository ini dibuat untuk menyimpan rangkuman materi, poin penting, dan pendapat saya selama mengikuti workshop. Selain itu, repository ini juga menjadi tempat latihan menggunakan GitHub untuk menyimpan dan mengelola proyek.

## Informasi Kegiatan

- Nama kegiatan: Lokakarya Proyek Hari 1
- Topik: From AI to GitHub (Building with AI, Managing Change with GitHub)
- Pemateri: Nugi Farhan, Senior Product Designer
- Tanggal: 7 November 2026

## Rangkuman Materi

1. Prompt Engineering: Cara memberikan perintah kepada AI agar hasilnya sesuai kebutuhan. Prompt yang baik terdiri dari Role (peran), Task (tugas), Context (konteks), dan Format (bentuk hasil).

2. Git: Alat untuk mencatat dan mengelola perubahan pada file atau proyek.

3. GitHub: Platform online untuk menyimpan repository Git dan bekerja sama dalam mengembangkan proyek.

4. Perintah Dasar Git: Beberapa perintah yang dipelajari yaitu `git init`, `git add`, `git commit`, `git push`, `git pull`, dan `git clone`.

5. Praktik Student Task Planner: Membuat aplikasi sederhana bernama Student Task Planner dengan bantuan AI, kemudian mempelajari cara menyimpan proyek tersebut ke GitHub.

## Poin Penting yang Saya Pelajari

- Prompt yang jelas dan memiliki konteks dapat membantu AI memberikan hasil yang lebih sesuai.
- Git dan GitHub memiliki fungsi yang berbeda. Git digunakan untuk mencatat perubahan, sedangkan GitHub digunakan untuk menyimpan repository secara online.
- Git membantu mengelola perubahan file melalui proses add, commit, dan push.
- AI dapat membantu proses pembuatan proyek, tetapi hasilnya tetap perlu diperiksa kembali.
- GitHub dapat digunakan untuk menyimpan tugas dan bekerja sama dalam proyek kelompok.
